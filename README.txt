PETUALANGAN BIMA & LALA — KOMIK FLIPBOOK INTERAKTIF

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder komik_flipbook_bima_lala.
3. Klik dua kali index.html, atau buka melalui browser Chrome/Edge/Firefox.
4. Gunakan tombol Sebelumnya/Berikutnya untuk membalik halaman.
5. Pada halaman kuis, klik pilihan jawaban untuk melihat hasil dan pembahasan.

ISI PROYEK
- index.html : struktur website
- style.css  : desain dan tampilan responsif
- script.js  : isi 12 halaman, navigasi, kuis, dan pembahasan

CATATAN
- Proyek ini menggunakan HTML, CSS, dan JavaScript murni.
- Koneksi internet hanya diperlukan untuk memuat font Nunito dari Google Fonts. Tanpa internet, website tetap dapat digunakan dengan font cadangan.
- Ilustrasi awal menggunakan emoji sebagai placeholder visual agar proyek langsung bisa dijalankan. Ilustrasi dapat diganti dengan gambar kartun AI/PNG sesuai arahan dosen.
- Materi dan soal merupakan rancangan awal; periksa kembali kesesuaian dengan capaian pembelajaran dan arahan dosen sebelum dikumpulkan.
